# AI Growth OS V3

这是根据小红书 AI Growth OS 六屏 UI 继续完善的高保真前端版本。

## 运行方式

项目现在包含一个 Node 原生本地后端，前端和 API 由同一个服务提供，无需安装第三方依赖：

```bash
npm start
```

然后打开 `http://127.0.0.1:4173/`。健康检查地址为 `http://127.0.0.1:4173/api/health`。

服务端配置复制 `.env.example` 为 `.env` 后填写。`.env` 只在服务端读取，不能提交到 Git。

## V3 重点完善

- 运营总览、数据分析、内容管理、任务中心、灵感库、账号设置、AI 运营总监完整页面。
- 桌面端三栏布局：左侧导航 + 主工作区 + AI 运营总监。
- 多断点响应式布局。
- Ctrl / Cmd + K 全局命令面板。
- AI 快捷提问、对话模拟、洞察转任务。
- 内容筛选、搜索、排序、批量选择。
- 任务筛选、创建、完成状态和 localStorage 持久化。
- 灵感推荐、选题大纲、选题转任务。
- 账号设置 / AI 偏好 / 通知设置。
- SVG 趋势图和数据卡片。
- Modal、Toast、移动端侧边栏等完整交互细节。

## 下一阶段建议

当前后端已经覆盖本地内测所需的认证、Session、用户隔离、AI 生成、历史、积分、每日赠送、会员权限和账号同步适配器。数据层仍是 `.data/store.json`，适合本地教学和单进程内测。

进入正式产品开发时建议迁移到：

- React + TypeScript + Vite
- React Router
- TanStack Query
- Zustand
- Recharts / ECharts
- 后端 API + PostgreSQL
- AI Agent 服务层
- 小红书数据授权/采集方案

其中小红书真实数据接入、自动发布等能力需要根据可用官方能力、授权与合规方案设计，不能仅靠前端实现。
